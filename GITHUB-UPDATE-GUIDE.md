## ✅ STEP-BY-STEP GUIDE:

### **STEP 1: Go to Your GitHub Repository**

1. Open browser

### **STEP 2: Find the Current File**

Look for the main HTML file. It might be named:

- Or similar

Click on that file to open it.

---

### **STEP 3: Delete the Old File**

1. Click the **file name** to view it
2. Click the **trash icon** 🗑️ (top right, says "Delete this file")
3. Scroll down
4. Add commit message: "Removing old version"
5. Click **"Commit changes"** (green button)

✅ Old file deleted!

---

### **STEP 4: Upload the New File**

1. Go back to main repository page
2. Click **"Add file"** button (top right)
3. Click **"Upload files"**
4. **Drag and drop** the new file I give you
   - OR click "choose your files" and select it
5. **IMPORTANT:** Name it exactly the same as the old file!
   - If old was `index.html`, name new file `index.html`
6. Scroll down
7. Add commit message: "Added file upload feature to Dataroom"
8. Click **"Commit changes"** (green button)

✅ New file uploaded!

---

### **STEP 5: Wait for GitHub Pages to Update**

1. GitHub Pages updates automatically
2. Wait **1-2 minutes**
3. Go to: https://barkanbaybogan.github.io/my-crm-project/
4. **Refresh the page** (Ctrl+F5 or Cmd+Shift+R)
5. **See your new version!** 🎉

## 📝 IMPORTANT NOTES:

### **File Naming:**
- If your current file is `index.html` → name new file `index.html`
- If your current file is `crm.html` → name new file `crm.html`
- **The name MUST match!**

### **GitHub Pages Settings:**
If your site doesn't update:
1. Go to repository **Settings**
2. Scroll to **Pages** (left sidebar)
3. Make sure Source is set to:
   - Branch: `main` (or `master`)
   - Folder: `/root` (or `/docs`)
4. Click **Save**
5. Wait 1-2 minutes
6. Refresh your site

## 💡 TROUBLESHOOTING:

**Problem:** Site not updating after upload
**Solution:** 
1. Wait 2-3 minutes (GitHub Pages takes time)
2. Hard refresh: Ctrl+F5 (Windows) or Cmd+Shift+R (Mac)
3. Clear browser cache
4. Try incognito/private window

**Problem:** Upload button not showing
**Solution:**
1. Make sure you uploaded the NEW file
2. Check file name matches old file
3. Hard refresh the page
4. Check browser console for errors (F12)

**Problem:** Site shows 404 error
**Solution:**
1. Check GitHub Pages is enabled (Settings → Pages)
2. Make sure file is named correctly
3. Wait 2-3 minutes for deployment
